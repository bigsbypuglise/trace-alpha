6. SHUTTLE TRANSPORT
--------------------
Rewind and fast-forward are SHUTTLE controls, not frame step.
Click ladder:  2x -> 5x -> 10x -> 30x -> 1x (fifth click)
The opposite button resets to 1x before reversing.
Single-frame movement is keyboard only: Left Arrow / Right Arrow. No on-screen button.

Rate indicator: centered above the transport, visible 900ms, fades over 200ms.
  Chip: padding 9/18, radius 8, panel.fill, 1px rgba(255,255,255,0.12)
  Label: mono 21px / 500, #FFFFFF, with the matching shuttle glyph at 19px
  Values: 2x 5x 10x 30x  and  -2x -5x -10x -30x   (1x uses the play glyph)


7. OVERLAY VISIBILITY
---------------------
Fade in    160ms ease-out on pointer move or key input
Fade out   240ms ease-out after 2.4s idle
Never auto-hides while the pointer is over the panel or a menu is open.
Fullscreen hides panel, filename chip and cursor together.
Honor the system reduced-motion setting: fades drop to 0ms.


8. MEDIA-SHAPED WINDOW
----------------------
The video viewport adopts the source DISPLAY aspect ratio exactly.
- Use DAR, not encoded dimensions. Anamorphic 2048x858 @ 2:1 PAR opens at its DAR.
- Apply rotation metadata first: 1920x1080 tagged 90 deg opens as a 9:16 window.
- Titlebar (38px) and menu bar are added OUTSIDE the viewport height.
- Transport floats over the image, excluded from layout.
- No permanent chrome inside the viewport. No internal bars. No crop. No stretch.

Opening size:
  100% of display size when it fits the work area with a 64px margin.
  Otherwise step down: 75% -> 50% -> 33% -> 25%. Never scale up past 100% on open.
  Minimum viewport short edge: 320px.
  9:16 caps at 90% work-area height; cinemascope caps at 90% work-area width.

Resize: with the lock on, any edge/corner drag constrains to the media ratio.

Constrained areas (fullscreen / maximize / Windows Snap):
  Preserve the whole image and its ratio. Fill the remainder with #000000.
  Bars must read as black against the #24272C viewport so the two states differ.
  Snap and maximize override the lock for their duration, then restore.

Menu item: Window > "Lock Window to Media Aspect Ratio" — checked by default.
  Unchecked, the window resizes freely and the image letterboxes inside it.


9. STATE SEMANTICS
------------------
Disabled       action exists but cannot run now (Zoom Out at min scale).
               icon 0.28, no hover.
Unavailable    this media can never support it (SMPTE Timecode with no embedded
               timecode; LucidLink link on a local file). Same rendering plus a
               tooltip stating why. NEVER hide the row.
Checked        accent wash + 1px accent inset AND a ui_check or ui_radio_selected
               glyph. State never depends on color alone.

11. SHARE MENU
--------------
Items: Copy File Path · Copy LucidLink Link · Show in File Explorer
States:
  Local file                  path + explorer enabled, LucidLink unavailable
  LucidLink file, integration all three enabled
  Non-file source             all three unavailable, tip "This media has no file on disk."
  Integration missing         LucidLink disabled, tip "LucidLink is not running.
                              Start the LucidLink client and reopen this menu."

share_copy_lucidlink is a NEUTRAL CHAIN GLYPH, not a LucidLink brand mark.
Replace only with a licensed official asset.


12. MOVIE INSPECTOR
-------------------
Two forms, same content: docked side panel (340px, attached right) and modeless
utility window (380px). Sections: General / Video Details / Audio Details,
each independently collapsible via ui_disclosure_*.

Values are selectable text with a right-click Copy affordance.
Long Windows and LucidLink paths WRAP, never truncate.
Missing metadata reads "Unknown". Present-but-unlabeled reads "Untagged".


13. ICON DELIVERY
-----------------
33 glyphs, 24 x 24 master grid, strokes 1.75-2.0px, rounded terminals,
currentColor only (no baked fills). Optical overshoot on circular glyphs is
intentional — do not renormalize to bounds.

base-ui-icons/svg/     master vectors
base-ui-icons/png/1x/  24px white on transparent
base-ui-icons/png/2x/  48px white on transparent

Apply state opacity at runtime. Do not ship separate per-state files.
There is deliberately NO frame-step icon in this set.
